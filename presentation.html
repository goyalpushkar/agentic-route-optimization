3. AI Tools & System Roles

The 6-Agent Ecosystem: From Order Sourcing to Booking

Modular event-driven architecture running on Google Cloud Run & Vertex AI

Agent 1: DC Sourcing & Profiler

• Slices orders by optimal origin DC.
• Normalizes 4D demand (Pallet, Cube, Case, Catch-Weight) across Frozen, Chill, Ambient, HMBC.

Agent 2: Fleet & Dock Allocator

• Catalogs 46W, 48W, 53W reefer capacities.
• Enforces 2-pallet bulkhead step rules.
• Validates retail dock length & liftgate limits.

Agent 3: Route Optimizer

• Solves MC-VRPTW with soft ±1hr windows.
• Enforces OTIF > Overtime > Miles > Fleet.
• Enforces reverse-drop LIFO loading sequence.

Agent 4: Live Rate Aggregator

• Broadcasts route specs to carrier APIs in parallel.
• Fetches live spot & contracted rates in <3s.
• Verifies carrier reefer availability.

Agent 5: Carrier Scoring & Booking

• Evaluates bids via 40/30/20/10 matrix.
• Locks booking via EDI 204/API.
• Signals WMS wave release ONLY after booking.

Agent 6: Cold-Chain Monitor

• Continuously tracks IoT reefer temps & GPS.
• Monitors delays against 30-min dock baseline.
• Triggers automated dynamic re-routes.
